# 🎵 Bryn Music Store

Platform katalog musik interaktif berbasis web untuk memamerkan dan mengelola audio tracks secara dinamis.

## 🚀 Fitur Utama
- **Katalog Dinamis:** Memuat daftar lagu secara real-time dari cloud database.
- **Audio Player Interaktif:** Pemutar musik bawaan dengan logika play/pause otomatis antar lagu.
- **Cloud Backend:** Terhubung langsung dengan Supabase untuk manajemen data dan storage audio.
- **Pemesanan Direct:** Integrasi tombol beli yang langsung terhubung ke WhatsApp dengan pesan kustom.
- **Desain Responsif:** Tampilan rapi dan optimal di perangkat desktop maupun smartphone.

## 🛠️ Teknologi yang Digunakan
- **Front-end:** HTML5, CSS3, JavaScript (ES6+)
- **Backend/Database:** Supabase (Database & Storage)
- **Deployment:** Vercel
